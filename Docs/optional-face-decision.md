# Optional Watch-inspired faces: scope decision

22 October 2026 · [#82 / EXTRA-01](https://github.com/Olli0103/homeview/issues/82)

**Decision: do not add Palette, Bounce-grid or Flux to this HomeView parity release.** The objective is to complete the evidenced HomeView backlog, not add unrequested Watch experiments. This completes an evaluation/decision issue; it is not an implementation or visual-parity PASS for these three concepts.

The dated [reference inventory](reference-catalogue.md) checked 24 archived sources, 51 visual references and four sampled original animations. None establishes these three names as required HomeView faces. Existing build/Watch hints are insufficient proof of a visible HomeView function. The inventory has explicit unobserved/unknown identities; this decision does not silently assign those images to a Watch name or claim that no future source could establish a connection.

| Candidate | Decision now | Evidence required to reopen |
| --- | --- | --- |
| Palette | Not included | Explicit product request or concrete original HomeView state; independently usable artwork and named color/time states |
| Bounce-grid | Not included | Explicit product request or concrete original motion; own geometry, interaction/Reduce Motion rules and bounded animation budget |
| Flux | Not included | Explicit product request or concrete original state sequence; own numerals/materials, time transitions and separate visual/lifecycle acceptance |

No new assets, dependency, renderer, shader, settings or face identities are introduced. The conditional requirement to define assets and acceptance **if adopted** is not triggered. Any future adoption must be scoped and accepted separately, including rights, accessible navigation, reduced motion, time zones and measured device behavior; it cannot close an unmet original feature by substitution.

The 105-function HomeView reference denominator is unchanged. Four already-existing optional layouts (Watch Modular, Infograph Modular, Modular Duo, Modular Compact) remain separately labeled; they are neither these three proposals nor a replacement for Snoopy/UI09. Snoopy/F015 was subsequently excluded by the owner for rights on 2026-10-29 ([scope decision](scope-exclusions.md)); it is not implemented or accepted. Other unobserved original behavior and blocked service/device work remain open.

Sources: [reference states](reference-states.json), [function mapping](function-coverage.json), [original backlog](backlog.md#extra-01). Research cutoff 16 October; archive verification 22 October. This scope decision uses that verified inventory, not a new public-source sweep or a universal absence claim.
