# Publication notes

The initial public snapshot is based on the private development checkpoint da4cd19, dated 17 October 2026. The private checkout and its history remain unchanged. Only application sources, project-owned configuration, tests and selected build scripts were copied into a fresh repository.

Excluded: all historical Evidence directories, reference screenshots and crops, original product icons, extracted digit contours, raw font/shader/binary analysis, private research paths, archive notes, build caches and previous Git history. The snapshot does retain our Swift numerical implementation of standard fluid operations and our original Metal glyph material. It contains no AIR dumps, OS libraries or private-framework loader.

All seventeen reference-derived raster fixtures were replaced by original geometric drawings generated by Scripts/prepare_assets.swift. FlowDigitShape was replaced by original seven-segment geometry. The app icon and demo tone are project-generated. Asset digests are in asset-manifest.json. These replacements deliberately change the public appearance; historical private screenshot comparisons are not a verification of this snapshot.

Build identifiers use org.example placeholders. Build cache paths resolve from the current user. There is no signing identity, provisioning profile, account token or live home configuration in the snapshot.

The initial snapshot was published without a general source license. Future external components require their own documented redistribution terms. Redistributable visual fixtures and typography remain separate parity work.
